# RH Sub-Proxy

یک رله‌ی بسیار سبک «لینک اشتراک» برای **سرور ایران**. درخواست‌های ساب را
(از طریق یک **SOCKS5**) به سرور اصلیِ خارج می‌فرستد و پاسخ را به کاربر ایرانی
برمی‌گرداند؛ پس کاربرانی که به‌خاطر فیلترینگ نمی‌توانند لینک ساب خارج را باز کنند،
از همین رله ساب خود را می‌گیرند.

```
کاربر(ایران) ─► http://<iran-server>:<port>/sub/<token>
                     │  (این رله)  ── SOCKS5 ──►
                https://panel.foreign:8000/sub/<token>  (اصلی)
                     └────────── محتوای ساب ───────────►  کاربر
```

## نصب (ساده، بدون nginx)

رله را با **وب‌سرور داخلی خود PHP** بالا می‌آورد (روی یک پورت، با systemd و
auto-restart). **هیچ nginx/استک سنگینی نصب نمی‌شود** تا با چیزهای موجود روی سرور
تداخل نکند. تنها نیاز: `php` (cli) + افزونهٔ `curl`؛ اگر نبودند، **فقط همان‌ها** و
**از طریق همان SOCKS5** نصب می‌شوند (برای سروری که apt مستقیم ندارد).

```bash
sudo bash install.sh
```
سه چیز می‌پرسد:
1. **پورت** (پیش‌فرض `8088`)
2. **آدرس ساب اصلی**: `https://panel1.rouhbakhsh.xyz:8000`
3. **SOCKS5**: `socks5://user:pass@127.0.0.1:8880` (خالی = مستقیم)

غیرتعاملی:
```bash
PORT=8088 TARGET=https://panel1.rouhbakhsh.xyz:8000 \
SOCKS5=socks5://user:pass@127.0.0.1:8880 sudo -E bash install.sh
```

تست:
```bash
curl -s http://127.0.0.1:8088/healthz        # → RH Sub-Proxy is running.
curl -s http://<server-ip>:8088/sub/<token>  # → همان محتوای ساب اصلی
```

مدیریت:
```bash
systemctl status rh-subproxy
systemctl restart rh-subproxy
journalctl -u rh-subproxy -n 50      # لاگ
```
تنظیمات: `/opt/rh-subproxy/config.php` (بعد از تغییر: `systemctl restart rh-subproxy`).

## اتصال به پنل/ربات
در پنل پاسارگارد یا پنلی که دارید، prefix لینک ساب را روی این رله بگذارید:
```
http://<server-ip>:8088     (یا دامنه/Cloudflare جلویش)
```
از این پس پنل لینک‌ها را با این آدرس می‌سازد و **ربات و مینی‌اپ خودکار همان را
می‌خوانند** — بدون هیچ تغییر کدی.

## SSL
این رله روی HTTP ساده بالا می‌آید. اگر HTTPS می‌خواهید، جلویش Cloudflare (ابر
نارنجی) یا ریورس‌پراکسی خودتان بگذارید.

## امنیت
- **پراکسی باز نیست:** فقط مسیرهای داخل `allow_paths` رله می‌شوند.
- `config.php` و لاگ خارج از مسیرهای مجازند.
- User-Agent کاربر حفظ می‌شود (فرمت درست v2ray/clash/sing-box/base64) و هدرهای
  متادیتای اشتراک (مصرف/انقضا/عنوان) عبور داده می‌شوند.

## فایل‌ها
- `index.php` — رله (در نصب، داخل `/opt/rh-subproxy/` نوشته می‌شود)
- `config.example.php` — نمونهٔ تنظیمات
- `install.sh` — نصب‌کننده‌ی ساده (فورواردر را خودش جاسازی می‌کند)

پرکسی ساکس 5 رو می تونید توی پنل های پاسارگارد و ثنایی بسازید
